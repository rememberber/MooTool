# 0.5.0 本机验收记录

- 验收系统：macOS 26.7，Intel x86_64；Swift 6.2.3 / Command Line Tools 26。
- 43 组核心测试通过，包括全部 24 项快速替换、UTF-16 选区、数字扩展与转义边界、列表前缀、XML 格式化、逐文档设置与旧工作区兼容，以及 Markdown 表格、任务列表和大小限制。
