# MooTool Next macOS Native 0.3.0

> Product: `next-macos-native`. Installation, data and releases remain independent of the Java, Electron and Tauri product lines.

## English

- Aligns JSON and Quick Note library layouts with Electron: search, content filtering, sorting, actions, folder tree and selected path.
- Adds folders, rename/move/duplicate/delete operations, drag moves and atomic UTF-8 file/folder imports.
- Restores per-document selection and scroll positions, JSON results and queries; keeps scratch content and synchronizes edits across native windows.
- Adds editor/split/preview note modes and validates real NSTextView interactions plus fresh application startup.

## 中文

- 按 Electron 的面板顺序补齐 JSON / 随手记文档库：搜索、正文检索、排序、操作栏、文件夹树和底部路径。
- 新增文件夹、新建/重命名/移动/复制/删除、拖动移动，以及整批成功后写入的 UTF-8 文件和文件夹导入。
- 按文档恢复选择与滚动位置、JSON 结果和查询；保留草稿内容，并验证原生窗口间编辑同步。
- 随手记提供编辑/分栏/预览模式，增加真实 NSTextView 操作和应用重新启动恢复验证。

## 日本語

- JSON とメモのライブラリを Electron に合わせ、検索、本文検索、並べ替え、操作欄、フォルダーツリー、パス表示を実装しました。
- フォルダー、名前変更、移動、複製、削除、ドラッグ移動と UTF-8 ファイル/フォルダーの一括読み込みを追加しました。
- 文書ごとの選択範囲、スクロール、JSON 結果とクエリを復元し、下書きと複数ウィンドウの編集を保持します。
- メモの編集/分割/プレビューモードを追加し、実際の NSTextView 操作とアプリ再起動時の復元を検証します。
