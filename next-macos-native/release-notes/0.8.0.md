# MooTool Next macOS Native 0.8.0

> Product: `next-macos-native`. Installation, data and releases remain independent of other MooTool product lines.

## English

- Rebuilds Text Diff as a dual-editor workspace with unified patch, navigation, and history parity.
- Documents layout limits and NSTextView highlighting boundaries in `docs/text-diff-workspace.md`.
- Time Convert, Cron builder, and five-tab Crypto workspace align with Electron panel order (`docs/parity.md`).
- Smoke acceptance polls text-diff unified output, JSON conversion input, and extends reformat/JSON waits to reduce flaky failures under load.
- Workbench: show-recent toggle, draggable sidebar width, hidden navigation tools, compact sidebar titles, HTTP proxy settings, message-board style persistence, and persisted split-pane widths in `workspace.json` (including image preview/options).
- Quick Note quick-replace keeps the editor selection when triggered from the panel, matching Electron’s selection-first behavior.
- Settings can merge layout, custom groups, pane widths, HTTP proxy, editor wrap/size, and vault Git auto-checkpoint options from Electron `mootool-next.json`.
- Crypto symmetric tab adds Electron-compatible AES/DES/SM4 ECB (UTF-8 keys, hex ciphertext) alongside AES-GCM.
- Crypto asymmetric tab adds RSA/SM2 algorithm picker; SM2 uses the same `sm-crypto` bundle as Electron via JavaScriptCore.
- Migration settings can merge HTTP, Host, translation words/history, generic tool history (`t_func_history`), and legacy tool drafts (`t_func_content`) from Electron `MooToolNext.db` or Java-compatible SQLite tables.
- Optional menu bar extra (tray) mirrors Electron tray actions: open, settings, screen color pick, region screenshot, translation, and Host profile switching.
- Main window close behavior (`general.closeBehavior`: ask / hide / quit) matches Electron; `autoDownloadUpdates` preference migrates but native builds still use manual update from GitHub Releases.
- Migration can import Java/Electron SQLite note and JSON document bodies (`t_quick_note`, `t_json_beauty`) into the native vault.
- Migration can import Electron on-disk `quick-notes` / `json-vault` folders (including `attachments/` images referenced from note bodies).
- Migration can import Java `~/.MooTool` disk vault folders (`quick-notes` / `json-beauty` via `config.setting`).
- Help menu and Settings → About check GitHub Releases API for updates (`autoCheckUpdates` on launch); opens download page when newer—no background installer yet.
- Settings language picker (zh-CN / en-US / ja-JP) localizes sidebar, home sections, settings category headers, workbench toolbar, history sheet, menu bar tray, color board toolbar, shared editor chrome, TextTool controls, HTTP request/response tabs and main actions; Vault Git panel (`git.*`), document vault disk refresh/Finder errors, legacy TextTool JSON/crypto subforms, JSON worker/`JSONEngine` host and worker validation messages (`JSONDispatch.js`), Cron human-readable `describe`/`naturalSummary`, and many Core tool errors (encode/config/regex/calculator/reformat/cron/protobuf, legacy AES-GCM digest, etc.) when `language` is set.
- Smoke/JSON acceptance use a 10s JSON worker timeout to reduce flakes when SwiftPM contends on `.build`.
- Reformat smoke acceptance waits longer for undo/history after format to reduce timing flakes under load.
- Translation tool adds translate / word book / history tabs with persisted word list split (`translation-words`).
- Color, regex, and cron tools support favorites (`toolFavorites`) with SQLite import from `t_next_favorite` or legacy `t_favorite_*` tables.
- Host tool adds Electron-style profile list/editor split; profiles persist in `workspace.json`.
- Image and PDF tools persist open file paths and export options across restarts when files remain on disk.
- QR, image, and PDF tools localize common user-visible error strings (generate, load, export, page range) in zh-CN / en-US / ja-JP.
- Expanded zh-CN / en-US / ja-JP coverage for JSON and Quick Note vault sidebars, Quick Note editor chrome, and JSON main workspace (toolbar, inspector, find/replace, dialogs, JSON history sheet), HTTP forms, Host, Cron, network diagnostics, translation (including word book/history), crypto five-tab UI, favorites sheet, message-board presets, code-run / hardware summary labels, regex form controls, Vault Git dialog, and partial TextTool chrome (encode swap, variables, calculator modes, cron preset menu, legacy JSON/crypto) (`docs/parity.md`).
- Core `ToolError` strings in `MooToolNextCore` (HTTP/cURL, vault library, Vault Git results, symmetric crypto, attachments, backup images, etc.) follow `language`; smoke reformat acceptance waits longer for undo/history under load.

## 中文

- 文本对比改为与 Electron 对应的双编辑器工作区，支持统一补丁、差异导航与历史恢复。
- 输入与高亮边界见 `docs/text-diff-workspace.md`。
- 时间转换、Cron 构建器、加密工具五标签工作区与 Electron 主要面板顺序对齐（详见 `docs/parity.md`）。
- 工作台：显示最近使用开关、可拖动侧栏宽度、侧栏工具显示/隐藏、仅图标导航、HTTP 代理、留言板样式持久化、更多工具分栏宽度（含图片预览/选项）写入 `workspace.json`。
- 随手记快速替换从面板触发时保留编辑器选区，与 Electron「有选区处理选区」一致。
- 设置支持从 Electron `mootool-next.json` 合并工作台布局、分栏宽度、HTTP 代理、编辑器字号/换行及文档库 Git 自动检查点。
- 加密对称标签新增与 Electron 一致的 AES/DES/SM4 ECB（UTF-8 密钥、Hex 密文），并保留 AES-GCM。
- 加密非对称标签支持 RSA/SM2 切换；SM2 通过内嵌 `sm-crypto` 与 JavaScriptCore 与 Electron 对齐。
- 设置「数据迁移」可从 SQLite 合并 HTTP/Host/翻译/通用工具历史（`t_func_history`）/工具草稿（`t_func_content`）/收藏等数据；翻译词库/历史、Host 多配置、颜色/正则/Cron 收藏；图片/PDF 状态可跨重启恢复。
- 可选菜单栏托盘：打开、设置、屏幕取色、区域截图、翻译与 Host 配置切换（设置 → 侧边栏可关闭）。
- 关闭主窗口行为（`general.closeBehavior`：询问 / 隐藏 / 退出）与 Electron 一致；`autoDownloadUpdates` 偏好可迁移，安装包仍通过「检查更新」手动获取。
- SQLite 可导入 `t_quick_note` / `t_json_beauty` 文档正文到原生文档库；亦可从 Electron 磁盘 `quick-notes` / `json-vault` 或 Java `~/.MooTool` 磁盘目录合并导入（含 `attachments/` 图片）。
- 帮助菜单与设置 → 关于通过 GitHub API 检查更新（支持启动时 `autoCheckUpdates`）；发现新版本可打开下载页，暂无后台安装器。
- 设置可选界面语言（简中 / 英语 / 日语），侧栏、首页、设置、工作台工具栏、历史弹窗、菜单栏托盘、调色板主控件、共享编辑器栏、TextTool 与 HTTP 主操作、Vault Git 面板、文档库磁盘刷新/Finder 提示、TextTool legacy JSON/加密子表单、JSON worker/`JSONEngine` 宿主与 worker 校验文案（`JSONDispatch.js`）、Cron 可读说明（`describe`/`naturalSummary`）及多数 Core 工具错误（编码/配置/正则/计算器/格式化/Cron/Protobuf、legacy AES-GCM 等，请求或调用携带 `language`）等随语言切换。
- 二维码、图片、PDF 工具的生成/加载/导出/页码等常见错误提示支持三语。
- 扩展 JSON/随手记文档库侧栏、随手记编辑区与 JSON 主工作区（工具栏/检查器/查找替换/弹窗与 JSON 历史 sheet）、JSON 结构树/路径选择面板、HTTP 表单、Host、Cron、网络诊断、翻译（含词库/历史）、加密五标签、收藏弹窗、留言板预设、代码运行与系统信息摘要、正则表单、编码/环境变量/计算器/Cron 部分 TextTool 控件等界面三语（详见 `docs/parity.md`）。
- Smoke / JSON 验收将 JSON 辅助进程超时放宽至 10 秒；文本对比、JSON 输入转换与格式化文件模式增加轮询等待，减轻负载下偶发失败。
- `MooToolNextCore` 内用户可见 `ToolError`（HTTP/cURL、文档库、Vault Git、对称加密、图片附件与备份等）已随 `language` 三语；格式化 smoke 验收加长撤销/历史等待。
- 菜单栏托盘操作状态、随手记 Markdown 预览与图片附件预览/插入提示（`tray.status.*`、`quickNote.preview.*`、`quickNote.image.*`）支持三语；legacy TextTool AES-GCM 使用稳定算法键调用 `TextServices.digest`。
