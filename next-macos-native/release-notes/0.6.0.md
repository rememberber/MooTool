# MooTool Next macOS Native 0.6.0

> Product: `next-macos-native`. Installation, data and releases remain independent of other MooTool product lines.

## English

- Adds note image attachments with an Electron-aligned toolbar entry, image paste and ordered multi-image drops.
- Preserves selection replacement, line breaks, undo/redo and document-switch protection.
- Adds local image previews, long-image scrolling, zoom and missing-image placeholders.
- Stores independent image files, retains references in document copies, exports notes with attachments and includes images in portable workspace backups.
- Supports older workspaces. Remote images, animation playback, automatic attachment cleanup and Git remain pending.

## 中文

- 随手记新增图片附件，按钮位置对齐 Electron，支持选图、剪贴板粘贴和多图顺序拖入。
- 保留选区替换、换行、撤销/重做语义，并防止过期导入结果写入其他文档。
- 新增本地图片预览、长图滚动、缩放和缺失图片占位说明。
- 图片保存在原生版独立目录，文档副本保留引用；导出可携带附件，便携备份包含图片内容。
- 兼容旧工作区。远端图片、动画播放、自动附件清理和 Git 仍待补齐。

## 日本語

- ノートに画像添付を追加し、Electron と同じ位置のボタン、クリップボードからの貼り付け、複数画像の順次ドロップに対応しました。
- 選択範囲の置換、改行、取り消し/やり直しを保持し、古い読み込み結果が別の文書に挿入されることを防ぎます。
- ローカル画像、縦長画像、ズーム、欠落画像の案内を表示します。
- 画像は独立したネイティブ版のディレクトリに保存し、文書の複製、添付画像を含む書き出し、持ち運び可能なバックアップと復元に対応しました。
- 旧ワークスペースを引き続き利用できます。リモート画像、アニメーション、自動添付ファイル整理、Git は未対応です。
