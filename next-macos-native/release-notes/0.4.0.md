# MooTool Next macOS Native 0.4.0

> Product: `next-macos-native`. Installation, data and releases remain independent of other MooTool product lines.

## English

- Aligns JSON with the Electron workflow: a main editor, collapsible inspector, find/replace bar, path picker and conversion dialogs.
- Adds undoable in-place formatting, compression and conversions; results can be copied, exported or applied explicitly.
- Adds JSONPath filters, recursive queries, slices and unions, duplicate-key detection, JSON/XML and JavaBean conversions.
- Ships its own fixed parser dependencies in a bounded native helper process; no Node.js or Electron installation is required.
- Preserves existing workspaces and validates native editing, dialogs, cancellation and restart recovery.

## 中文

- JSON 按 Electron 工作流调整为主编辑器、可折叠检查器、查找替换栏、路径选择和转换弹窗。
- 格式化、压缩与原地转换支持撤销；查询和输出转换先展示结果，由用户复制、导出或使用。
- 新增 JSONPath 筛选/递归/切片/联合查询、重复键检测，以及 JSON/XML、JavaBean 转换。
- 原生版自带固定版本解析依赖和可超时/取消的辅助进程，无需安装 Node.js 或 Electron。
- 兼容已有工作区，验证原生编辑、弹窗、取消和重启恢复。

## 日本語

- JSON を Electron と同じ操作構成に合わせ、メインエディター、折りたたみ可能なインスペクター、検索置換、パス選択と変換ダイアログを実装しました。
- 整形、圧縮と変換を元に戻せます。出力は確認してからコピー、書き出し、適用できます。
- JSONPath のフィルター、再帰検索、スライス、複数選択、重複キー検出、XML と JavaBean の変換を追加しました。
