# MooTool Next macOS Native 0.1.0

> Product: `next-macos-native`. This application installs independently of MooTool Java, Electron and Tauri.

## English

- Introduces an independent SwiftUI/AppKit application with 26 tool entries, native navigation, search, appearance settings and tool windows.
- Adds local documents, history, workspace backups and native media/system integrations.
- This first version implements the core tool workflows. Advanced Electron features are not all included; consult `docs/parity.md` before choosing a workflow.

## 中文

- 新增独立的 SwiftUI/AppKit 原生应用，包含 26 个工具入口、原生导航、搜索、主题设置和独立工具窗口。
- 支持本地文档、历史记录、工作区备份及 macOS 媒体/系统框架。
- 首版实现核心工作流程，尚未包含 Electron 的全部高级功能，具体差异见 `docs/parity.md`。
