# MooTool Next macOS Native 0.5.0

> Product: `next-macos-native`. Installation, data and releases remain independent of other MooTool product lines.

## English

- Aligns the note toolbar and quick replacement panel with Electron, using native macOS controls and compact layouts.
- Saves font, size, category color, line spacing, wrapping and syntax per document.
- Adds 24 undoable quick replacements, selection/full-document behavior, find/replace and list actions.
- Adds Markdown tables, task lists and fenced code previews; switching preview modes preserves editor undo.
- Preserves older workspaces and verifies native interactions, multiple windows and restart recovery. Attachments, Git and remaining advanced editor features are still pending.

## 中文

- 随手记工具栏和快速替换面板按 Electron 的操作顺序对齐，适配 macOS 原生控件和窄窗口。
- 字体、字号、分类颜色、行距、换行和语法按文档保存与恢复。
- 新增 24 项可撤销快速替换，保留选区/全文语义，补齐查找替换和列表操作。
- 新增 Markdown 表格、任务列表和围栏代码预览；切换预览模式保留编辑器撤销记录。
- 兼容旧工作区，验证原生交互、多窗口和重启恢复。附件、Git 及其余高级编辑功能仍待补齐。

## 日本語
