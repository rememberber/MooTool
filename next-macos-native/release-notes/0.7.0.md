# MooTool Next macOS Native 0.7.0

> Product: `next-macos-native`. Installation, data and releases remain independent of other MooTool product lines.

## English

- Reformats the Reformat tool into Electron-aligned text and file workspaces with embedded formatters.
- Preserves legacy JSON/XML reformat drafts and history.

## 中文

- 格式化工具改为与 Electron 对应的文本 / 文件双工作区，内嵌 Prettier、Java/XML 插件与 Nginx 格式化器。
- 文本模式原位格式化且可撤销；文件模式原文与只读结果双栏、UTF-8 导入导出。
- 兼容旧原生 JSON/XML 草稿与历史记录；工作区可恢复格式化类型、缩进与文件内容。

## 日本語

- 整形ツールを Electron と同様のテキスト / ファイルワークスペースに変更し、フォーマッターを同梱しました。
- 旧ネイティブ版の JSON/XML ドラフトと履歴を引き続き利用できます。
