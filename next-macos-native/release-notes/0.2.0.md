# MooTool Next macOS Native 0.2.0

> Product: `next-macos-native`. Application identity, installation and data remain independent of the Java, Electron and Tauri products.

## English

- Adds HTTP request collections, cURL import/export, query parameters, cookies, form bodies, timeout/redirect settings and separate response views.
- Adds a native JSON structure tree, node/path copying, indentation options and JSON string escaping.
- Restores the new settings through drafts, history and backups while retaining compatibility with 0.1.0 workspaces.
- Verifies loopback HTTP redirects, cookie isolation, request round trips, JSON structure limits and expanded native view coverage.

## 中文

- HTTP 新增请求集合、cURL 导入导出、查询参数、Cookie、表单正文、超时/重定向设置和独立响应面板。
- JSON 新增原生结构树、节点/路径复制、缩进选项和字符串转义。
- 新设置随草稿、历史和备份恢复，兼容读取 0.1.0 工作区；切换工具后仍可取消 HTTP 请求。
- 增加真实本机重定向、Cookie 会话隔离、请求往返、结构树边界和原生界面验证。

## 日本語

- HTTP リクエストコレクション、cURL の読み込み/書き出し、クエリ、Cookie、フォーム本文、タイムアウト/リダイレクト設定とレスポンス別表示を追加しました。
- JSON 構造ツリー、ノードとパスのコピー、インデント設定、文字列のエスケープを追加しました。
- 新しい設定は下書き、履歴、バックアップに保存され、0.1.0 のワークスペースも読み込めます。
- ローカル HTTP、Cookie 分離、JSON 構造の制限およびネイティブ画面の検証を拡充しました。
