# AES 与正则兼容性修复

## AES

- AES/ECB/PKCS7 与 Java 默认 AES/ECB/PKCS5Padding 对齐；密钥使用原始 UTF-8 字节，支持 16/24/32 字节。
- 不再截断或补字符 0；非法长度明确拒绝，多字节字符按字节长度判断。
- 解密校验完整密文块与填充，允许合法空明文。
- 旧 Electron 截断/补零产生的密文，可勾选“旧 Electron 密钥处理（仅解密）”读取。不会自动回退，也不会用旧规则生成新密文。
- 未改变 DES/SM4 的既有密钥规则；其他算法不属于本次修复。

## 正则

- 默认 Java 兼容模式，运行固定的 Java Pattern/Matcher 程序，用户的表达式与文本通过 stdin Base64 协议传入，不拼接到代码或命令参数。
- 使用设置中的 Java 可执行文件，或自动发现的 Java；需要 JDK 11+ 支持源码启动。未安装时显示错误及运行环境说明，不静默切换引擎。
- JavaScript 模式保留原有 RegExp 语义，在独立 Web Worker 执行。两种模式名称明确可见。
- Java 子进程超时 5 秒，JS Worker 超时 2 秒；新输入取消旧任务，旧结果不会覆盖新结果。
- 输入限表达式 16000 字符、原文 1000000 字符；最多显示 5000 条匹配，Java 另有内存和输出限制。
- 输入、选项、引擎变化后防抖自动匹配；原文高亮，点击匹配结果定位，并支持上一个/下一个匹配。偏移使用 UTF-16，与编辑器一致。
- 手动匹配写入历史，自动匹配不刷历史；草稿恢复包含表达式、文本、选项和引擎。
- 抽取 Cron 收藏管理为共用组件，正则支持分组、新建、重命名、编辑、多选删除与排序。Cron 继续使用相同功能。

## 验证

- 固定 Java AES-192 密文样例；AES-128/192/256 与多字节密钥使用 Node 标准实现交叉验证；覆盖非法长度、空明文、坏填充、旧密文。
- 实际 Java 子进程集成测试覆盖 `\\Q…\\E`、字符类交集、占有量词、内联标志、空捕获组、UTF-16 位置、零宽匹配、错误、结果上限、取消和超时。
- Electron 流程验证实时高亮、导航、引擎切换、JS 超时后的恢复、草稿恢复、收藏编辑、AES 兼容及旧密文读取；同时回归 Cron 收藏流程。
