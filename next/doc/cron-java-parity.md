# Cron：Java 功能对齐

对照 Java 的 `CronForm`、`CronListener`、`CommonCronDialog`、`FavoriteCronForm` 和 `CronExpressionUtil`。

| Java 功能 | Electron 实现 |
| --- | --- |
| 秒、分、时、日、月、周、年配置 | 七字段编辑与可视化页签；每个值、起点/步长、范围、多选、自定义 |
| 日与周特殊规则 | `?`、`nW`、`L`、`nL`、`n#k`；另支持 `LW`、`L-n` |
| 可选年份 | 省略、每年、范围，另支持列表和步长 |
| 反解析到 UI | 回填字段及对应规则；月/星期名称转为数字 |
| 表达式变更后的未来 10 次执行 | 防抖自动更新，保留手动解析和时区选择；有限计划返回剩余次数，过期计划返回空列表 |
| 自然语言 | 独立选择中、英、日语言，转换记录写入历史 |
| 常用表达式 | Java 中全部 30 个示例去重后 22 条；保留历史年份，可点击使用 |
| 收藏夹 | 新建、重命名、删除分组；添加、编辑名称/表达式/备注、应用、删除收藏；多选删除和上下移动，持久化顺序 |
| 历史 | 回填输入、描述语言和时区，再计算未来执行时间 |
| Linux 与 Quartz | Linux 五段及常用 `@` 别名；Quartz 六/七段，星期 1=周日、7=周六 |

Quartz 的日期与星期互斥，编辑器自动维护 `?`。Java 月份页中“不指定”会生成无效的月份 `?`，Electron 使用 `*` 表示所有月份，不复制该无效输出。

Linux 同时限制日期与星期时采用 OR 语义，正常计算和描述；这种表达式无法等价转为单条 Quartz，反解析明确报错，保留原始输入。

验证覆盖：Cron 引擎单测、收藏库迁移/编辑/排序持久化测试、Electron 可视化规则/反解析/常用表达式/描述语言/收藏完整流程及紧凑窗口检查。
