# 文件快速预览

Electron 版日常工具新增“文件快速预览”，命令面板可用 `peek`、`preview`、`预览` 搜索。参考 [PowerToys Peek](https://learn.microsoft.com/en-us/windows/powertoys/peek) 的批量预览和文件切换交互。本版入口是 MooTool 内的文件选择或拖入，不接管系统文件管理器的空格键。

## 使用

- 点击“选择文件”多选，或将文件拖入预览工作区（包括文本编辑器区域）。每次选择/拖入替换当前批次；每批最多 100 个文件，超限会保留上一批并提示。
- 点击列表、上一文件/下一文件，或在非文本控件中按左右键切换；到首尾停止。文本选择、编码选择和 PDF 页码输入保留自己的按键行为。
- 文本/JSON 点击“查找”或按 ⌘F / Ctrl+F，在当前显示内容中查找。支持字面文本、区分大小写、全词匹配，显示匹配总数并可前后跳转；到首尾会循环并提示。Enter 查找下一处，Escape 先关闭查找栏。查询最多 256 个字符，不提供替换或正则模式。
- 同一批次往返查看时，分别保留每个文件的编码、换行、JSON 格式化、文本选择/滚动位置、查找设置、图片缩放，以及 PDF 页码/缩放。缓存只保存阅读设置；切换仍释放旧内容和 PDF worker。每次选择/拖入新批次或清空后重置，重启不保存。
- 显示文件名、文件大小、修改时间和批次位置。未知类型、损坏文件或超限文件仍保留在列表中，方便继续切换。
- 可使用现有独立工具窗口，分离/停靠保持当前批次。窄窗口列表横向排列，支持浅色/深色和中英日界面。
- 预览只读；仅点击复制时写入剪贴板。不会写入源文件、图片库、JSON 库、历史或收藏。批次只保留在当前工具窗口内，不跨应用重启保存。

## 格式与限制

| 类型 | 功能 | 单文件上限 |
| --- | --- | ---: |
| 文本/源码 | 复用 TextCodeEditor、行号、语法高亮、折叠、换行、查找、复制 | 2 MiB |
| JSON/JSONC | 原文/格式化切换；无效 JSON 仍显示原文；token 格式化保留大整数、重复键、JSONC 注释 | 2 MiB |
| PNG/JPEG/GIF/WebP/BMP/ICO/AVIF | 本地 Blob 图片、尺寸、适应窗口、100%、缩放 | 32 MiB |
| PDF | 本地 canvas 页面渲染、页码选择、翻页、适应宽度、缩放 | 50 MiB |

自动文本编码为 UTF-8 或带 BOM 的 UTF-16 LE/BE；也可显式选择 UTF-8、UTF-16 LE/BE、GB18030。严格解码失败时提示切换编码，二进制内容拒绝作为文本展示。扩展名覆盖常见文本、源码、配置和日志文件；HTML、SVG、Markdown 显示源码，不创建 HTML 页面或外部资源预览。

每次只读取当前选中的文件。切换后释放旧图片 Blob URL；PDF 加载/绘制取消并销毁所属 worker，损坏文件加载失败也释放 worker。旧异步读取不会覆盖当前文件。清空批次或关闭工具同样释放资源。预览中超出一百万字符的文本使用现有编辑器的轻量模式。

PDF.js 6.4.299 固定为构建依赖，渲染器和 worker 由 Vite 打包；`prepare:preview-pdf` 从已安装依赖复制 CMap、标准字体、WASM 和许可证到被忽略的 `public/pdfjs`，在 dev/build 前执行并由 Vite 放入最终安装包。无需 CDN、Python 或运行时下载。仅渲染页面，不运行 PDF JavaScript，也不提供链接、附件、交互表单或密码输入；密码保护文档会提示暂不支持。

PDF 每张页面的 canvas 不超过 800 万像素、单边不超过 8192，内部解码图片上限 3200 万像素。极复杂文档的解析耗时和内存仍取决于文档内容；这些限制不是整体内存上界。图片字节上限也不是解码内存上界。

## 验证

- `npm run check`：83 个测试文件、412 项测试，类型检查和构建通过。新增字面搜索、大小写/全词规则、双向循环以及大文件计数检查；扫描不会保留全量匹配位置数组。
- `npx playwright test tests/electron/file-preview.spec.ts`：6 项真实 Electron 桌面测试，其中 5 项覆盖文件预览：混合批次、拖入编辑器、键盘导航、只读、精确 JSON 格式化、中文旧编码、损坏/未知/超限文件、PDF 像素与翻页、文件切换及错误后的 worker 释放、源文件完整性，以及窄屏深色独立窗口和分离/停靠。补充混合文件往返恢复阅读设置、⌘F/Ctrl+F、搜索高亮/计数、滚动恢复、Escape 不误关闭窗口，以及新批次设置重置。另 1 项确认 JSON 工具原查找栏仍保留正则和替换入口，高亮结果正确。
- PDF 测试包含 JavaScript OpenAction，确认不会执行；预览期间未发起 HTTP(S) 请求。属于当前测试语料的观察结果。
- 第一版 macOS arm64 的临时目录打包应用中，4 项桌面测试通过；另补中文 Type0/CID 字体 PDF 渲染检查并查看截图，汉字显示正常。安装包内含本地 PDF worker、CMap、字体和 WASM；没有额外打入 PDF.js 的 Node 原生 Canvas 依赖。本批查找与阅读状态改进在源码构建的 Electron 中验证。
- 工具搜索及最近访问回归测试通过。
- 额外运行 `app.spec.ts` 中旧的 `formats JSON and completes history and Vault workflows` 综合用例未通过：它在默认双栏状态下断言三栏布局的 `json-three-pane` 持久化键。本批未改该综合用例；共享查找栏的兼容性由上述独立 JSON 回归测试验证。

本机验证平台为 macOS arm64。Windows/Linux 使用相同渲染器和浏览器文件 API，但还未做目标系统实机验收。
