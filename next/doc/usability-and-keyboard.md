# 弹窗、提示与任务反馈

## 弹窗与键盘

通用弹窗打开后，焦点进入明确指定的控件、表单输入或底部操作按钮。Tab / Shift+Tab 在当前弹窗和其菜单之间循环；背景不可交互。Esc 关闭最上层弹窗，关闭后恢复到打开它的控件。删除等危险确认默认聚焦“取消”。点击遮罩默认保留弹窗及已输入的内容，关闭请使用取消、关闭按钮或 Esc。

弹窗所属的浮动菜单与提示使用 `DialogPortal`，保持在同一焦点范围内。`Dialog` 的 `dismissOnBackdrop` 可供明确需要遮罩关闭的场景单独启用。

“设置 → 常规 → 按 Esc 隐藏窗口”控制未被控件处理的 Esc：默认保持隐藏主窗口、收回独立工具的行为；关闭后只保留弹窗、搜索和菜单本身的 Esc 操作。设置立即生效并在重启后保留，旧设置自动迁移为开启。

## 错误提示

错误默认一直显示到手动关闭，可以选中文字或点击“复制错误信息”。相同的文字错误合并展示，普通成功提示不会挤掉未读错误；多条错误可滚动查看。成功及一般通知继续默认约 3.2 秒后消失。调用方仍可显式指定通知时长。

## JSON 无选中文件

未选中文件时，工作区显示“新建片段”“导入文件”“用示例新建”，左侧仍可选择已有片段。导入和示例会先打开命名弹窗，确认后才保存为片段；导入保留原始 JSON 文本，包括大整数和重复键，不改写来源文件。建议名称避开当前树中已有的同名文件。

## PDF 结果与取消

成功结果提供“打开文件”“在文件夹中显示”“复制路径”，完整路径可悬停查看。主进程只允许发起该操作的 renderer 访问最近一次成功生成的输出文件，操作时再次检查文件类型，系统打开失败会显示可复制的错误。

任务取消后显示“已取消”，受影响行也保留取消状态；请求取消后按钮显示“正在取消”。关闭合并保存对话框同样显示取消状态。文件提交阶段禁用取消，其余处理沿用后台任务与暂存文件机制：取消不改写原来的目标文件。具体提交边界见 [后台计算与工具恢复](performance-and-recovery.md)。

## 验证

`npm run check` 覆盖类型检查、单元测试和生产构建。`tests/electron/user-experience.spec.ts` 覆盖弹窗焦点、遮罩保护、错误提示停留与复制、JSON 三个入口、PDF 结果操作与真实取消、Esc 默认值及重启和独立工具实时设置；PDF 结果另检查浅色、深色和窄窗口布局。现有 `medium-parity`、命令面板、文件预览、后台任务和独立窗口用例用于交互回归。
