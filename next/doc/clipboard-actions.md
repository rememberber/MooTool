# Electron 剪贴板格式转换

打开命令面板，搜索并执行以下动作。打开面板或搜索不会读取剪贴板；执行后先显示文本预览，只有点击「复制结果」才改写剪贴板。

| 动作 | 搜索命令 | 默认保存格式 |
| --- | --- | --- |
| 富文本转 Markdown | `markdown` / `富文本转 Markdown` | `.md` |
| 表格转 JSON | `table json` / `表格转 JSON` | `.json` |
| 剪贴板纯文本 | `clipboard text` / `剪贴板文本` | `.txt` |
| 剪贴板 HTML 源码 | `clipboard html` / `剪贴板 HTML` | `.html` |

这些动作可设为常用，也会出现在最近执行中。常用动作与托盘快捷入口同步。只持久化动作 ID，不保存剪贴板内容、转换结果或导出路径。

## 富文本转 Markdown

读取一次文本/HTML 快照，有 HTML 格式时转换 HTML；只有纯文本时原样保留。支持常见段落、标题、加粗、斜体、删除线、引用、列表、链接、行内代码、代码块和普通表格。表格首行作为 Markdown 表头。

HTML 存入惰性的模板片段，始终不插入活动页面。脚本、样式、表单、嵌入对象等不参与转换；图片仅保留说明文字，不下载或嵌入图片。链接保留 HTTP、HTTPS、mailto 地址，其他链接只保留可见文字。字号、颜色、布局等样式不保留，这不是完整的富文本排版转换器。

「剪贴板 HTML 源码」则原样预览及保存 HTML 文本，包括原有标签；应用不会渲染或执行它。无 HTML 格式时报错，不会把纯文本伪装为 HTML。

## 表格转 JSON

优先转换 HTML 快照中的第一张表格；没有表格时解析剪贴板文本。支持电子表格常见的 TSV，也支持 CSV：优先选择首行引号外的制表符，否则使用逗号；单列表格按换行解析。双引号字段可包含换行和分隔符，两个双引号表示一个字面双引号。

首行作为列名，去除列名首尾空白。列名不能为空或重复，每行列数必须相同；不推断数字、布尔值或日期。`001`、`true`、空单元格均保留为字符串。HTML 单元格去除首尾空白，`<br>` 转为换行。合并单元格、嵌套表格和不完整行会报错，不会静默丢弃数据。

最多支持 200 列、5000 行数据。动作输入最多 100,000 个字符，HTML 与文本快照分别检查此限制。HTML 最多包含 5000 个元素，Markdown 转换限制嵌套深度为 100 层。

## 保存预览

所有文本动作结果，包括既有 UUID、JSON、编码等结果，都可选择 `.txt`、`.md`、`.json`、`.html` 后点击「保存为文件」。原生保存对话框负责选择路径及确认覆盖，应用以 UTF-8 写入当前预览快照。改变剪贴板不影响已显示的预览，选择扩展名也不转换内容。

选择 `.json` 时先检查 JSON 语法，不合法则不打开保存对话框。取消保存不写文件，也不显示成功提示；保存失败保留预览供重试或复制。保存本身不改写剪贴板。没有自动模拟按键或向其他应用粘贴，也不监视剪贴板历史。

命令后带文本参数时，直接处理该参数，不读取剪贴板；`markdown 参数` 原样保留纯文本，`table json 参数` 解析 TSV/CSV，`clipboard html 参数` 原样保留显式 HTML 字符串。

## 验证

- `npm run check`：类型检查、单元测试、生产构建。
- `npx playwright test tests/electron/clipboard-actions.spec.ts tests/electron/command-palette.spec.ts tests/electron/command-preferences.spec.ts`：真实 HTML/文本剪贴板、Markdown 常见结构、代码块换行、脚本及远程资源隔离、HTML 表格、UTF-8 文件内容、JSON 检查、取消和写入失败、过期读取、常用/最近记录、紧凑布局、浅深主题，以及停靠原生工具上方的命令面板。

桌面测试运行于 macOS，输出均位于临时目录；Windows/Linux 尚未实机验收。
