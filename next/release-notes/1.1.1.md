# MooTool Next Electron 1.1.1

## English

> Product: MooTool Next Electron<br>
> Version: 1.1.1<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Features

- Added the Claude theme.
- Notes and JSON Workbench support switching editor fonts.
- Notes and JSON lists add right-click actions: delete, open in Finder/File Manager, and recursive deletion of empty folders.
- Changing a note type now syncs the file extension.

### Fixes and improvements

- Find & Replace with regular expressions now supports `\n` newlines.
- Darkened selection and current-row background colors for better readability.
- Refined the About / homepage support description for building and improving MooTool.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.1.1<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 新功能

- 新增 Claude 主题。
- 随手记与 JSON 工作台支持切换编辑器字体。
- 随手记 / JSON 列表增加右键操作：删除、在 Finder/文件管理器中打开，以及递归删除空文件夹。
- 更改笔记类型时同步更新文件扩展名。

### 修复与改进

- 查找替换在正则模式下支持 `\n` 换行。
- 加深选中背景与当前行背景色，提升可读性。
- 优化首页 / 关于中的支持说明文案。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.1.1<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 新機能

- Claude テーマを追加しました。
- クイックノートと JSON ワークベンチでエディターフォントの切り替えに対応しました。
- クイックノート／JSON リストに右クリック操作を追加：削除、Finder／ファイルマネージャーで開く、空フォルダーの再帰削除。
- ノート種別の変更時にファイル拡張子を同期します。

### 修正と改善

- 正規表現の検索／置換で `\n` 改行に対応しました。
- 選択背景と現在行の背景色を濃くし、視認性を向上しました。
- ホーム／About のサポート説明文を調整しました。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
