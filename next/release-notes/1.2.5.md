# MooTool Next Electron 1.2.5

## English

> Product: MooTool Next Electron<br>
> Version: 1.2.5<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- The main window can use a window material: Automatic, Solid, Vibrancy, or Liquid Glass. The choice applies on the next launch.
- Automatic mode uses native Liquid Glass on macOS 26 and newer, falls back to vibrancy when that is unavailable, uses vibrancy on earlier macOS, and stays solid on Windows and Linux.
- Reduced transparency and high contrast keep the main window solid.
- Sidebar hover and selection use translucent neutral layers, so the window material stays visible.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.2.5<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- 主窗口可以在设置中选择窗口材质：自动、实色、毛玻璃或 Liquid Glass。选择在下次启动时生效。
- 自动模式在 macOS 26 及更新版本上使用原生 Liquid Glass；不可用时回退为毛玻璃。较早的 macOS 使用毛玻璃，Windows 和 Linux 保持实色。
- 系统开启减少透明度或高对比度时，主窗口使用实色。
- 侧栏的悬停和选中改用半透明中性色层，窗口材质仍然可见。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

### 修正と改善

- メインウィンドウの質感を、自動、不透明、すりガラス、Liquid Glass から選べます。選択は次回起動時に適用されます。
- 自動では、macOS 26 以降でネイティブの Liquid Glass を使います。利用できない場合はすりガラスに戻ります。それより前の macOS ではすりガラス、Windows と Linux では不透明のままです。
- 透明度を下げる設定や高コントラストが有効なときは、メインウィンドウを不透明にします。
- サイドバーのホバーと選択は半透明の中間色になり、ウィンドウの質感が見えたままになります。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
