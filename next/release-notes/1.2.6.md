# MooTool Next Electron 1.2.6

## English

> Product: MooTool Next Electron<br>
> Version: 1.2.6<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Window material now also applies to detached tool windows. Settings show the material actually in use, why it was reduced, and whether a restart is still required.
- Detached windows keep the immersive tool header and native traffic lights. Floating controls such as detach, dock, and view switching use a glass style when a translucent material is active.
- A collapsed sidebar shows tool names. The sidebar scrollbar is hidden, and the first navigation item is named MooTool.
- The JSON options panel starts collapsed.
- Code and text editors use a slightly heavier default weight, and the active-line highlight meets the line-number gutter without a gap.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.2.6<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- 窗口材质也会应用到独立工具窗口。设置中会显示当前实际材质、降级原因，以及是否仍需重启。
- 独立窗口保留沉浸式工具顶栏和原生红绿灯。拆出、收回、视图切换等浮动控件，在半透明材质下使用玻璃样式。
- 收起侧栏后仍显示工具名称。侧栏滚动条不再常驻，导航第一项改名为 MooTool。
- JSON 选项面板默认收起。
- 代码和文本编辑器的默认字重略微加粗，当前行高亮与行号栏之间不再留缝。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.2.6<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 修正と改善

- ウィンドウの質感を、分離したツールウィンドウにも適用します。設定には実際の質感、簡略化された理由、再起動がまだ必要かを表示します。
- 分離ウィンドウは没入型のツール上部とネイティブの信号ボタンを維持します。分離、収納、表示切替などの浮遊コントロールは、半透明の質感ではガラス風になります。
- サイドバーを折りたたんでもツール名を表示します。サイドバーのスクロールバーは常時表示せず、先頭の項目名は MooTool です。
- JSON のオプションパネルは初期状態で折りたたまれます。
- コードとテキストのエディターは、既定の字重をわずかに太くし、現在行の強調と行番号の背景のすき間をなくしました。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
