# MooTool Next Electron 1.0.9

## English

> Product: MooTool Next Electron<br>
> Version: 1.0.9<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Features

- Host find & replace now matches Notes; JSON and Host lists support searching file names and file contents.
- Host list adds a right-click menu for rename, export, delete, and other common actions.
- Notes / JSON Git commit diffs now use a side-by-side before/after comparison, aligned with the Java edition.
- HTTP tool supports a custom request timeout, and the response body panel includes search.
- Message Board can keep the display awake.

### Fixes

- Fixed Notes automatic Git commit no longer working.
- Removed the outer black border when Message Board is shown in immersive mode.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.0.9<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 新功能

- Host 查找替换与随手记对齐；JSON 与 Host 列表支持按文件名及文件内容搜索。
- Host 列表增加右键菜单，支持重命名、导出、删除等常用操作。
- 随手记 / JSON 的 Git 提交差异改为左右对照展示，与 Java 版一致。
- HTTP 工具支持自定义超时时间，响应 Body 区域支持搜索。
- 留言板支持保持屏幕常亮。

### 修复

- 修复随手记自动提交不再生效的问题。
- 修复留言板沉浸模式下外层黑边问题。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.0.9<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 新機能

- Host の検索／置換をクイックノートと揃え、JSON／Host リストでファイル名およびファイル内容の検索に対応しました。
- Host リストに右クリックメニューを追加し、名前変更・エクスポート・削除などの操作ができます。
- クイックノート／JSON の Git コミット差分を左右比較表示にし、Java 版に揃えました。
- HTTP ツールでリクエストタイムアウトをカスタムでき、レスポンス Body の検索にも対応しました。
- 伝言板でディスプレイのスリープ防止（常時点灯）に対応しました。

### 修正

- クイックノートの自動コミットが動作しなくなっていた問題を修正しました。
- 伝言板のイマーシブ表示時に外側の黒い枠が出る問題を修正しました。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
