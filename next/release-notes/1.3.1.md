# MooTool Next Electron 1.3.1

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.1<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Batch Rename previews new names, then renames up to 500 regular files. Rules include find and replace, prefix, suffix, and numbering. Conflicts block the batch. The last successful batch can be undone, and an interrupted batch can be recovered.
- The command palette can generate a UUID, convert a timestamp, format or minify JSON, encode or decode Base64 and URL text, and remove duplicate lines. Actions can be pinned, and recent actions stay at the top.
- A global shortcut opens the command palette while MooTool is in the background. The default is ⌘⇧Space on macOS and Ctrl+Shift+Space on Windows and Linux. Pinned actions are also available from the tray.
- The JSON workspace status bar shows the current file path and an unsaved marker.
- Dark mode uses the Islands Dark palette for tool workspaces. The application sidebar keeps its own material.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.3.1<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- 新增批量重命名：先预览新文件名，再重命名最多 500 个普通文件。规则包括查找替换、前缀、后缀和连续编号。存在冲突时整批不执行。最近一次成功的批次可以撤销，中断的批次可以恢复。
- 命令面板可以生成 UUID、把时间戳转为日期、格式化或压缩 JSON、编解码 Base64 和 URL，以及去除重复行。动作可以设为常用，最近执行的动作会排在前面。
- 全局快捷键可在 MooTool 处于后台时打开命令面板。默认是 macOS 的 ⌘⇧Space，以及 Windows 和 Linux 的 Ctrl+Shift+Space。常用动作也可以从托盘打开。
- JSON 工作区状态栏显示当前文件路径和未保存标记。
- 深色模式的工具工作区改用 Islands Dark 配色。应用侧栏仍使用自己的材质。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>

### 修正と改善

- 一括リネームを追加しました。新しい名前をプレビューしてから、最大 500 個の通常ファイルを改名します。検索と置換、接頭辞、接尾辞、連番に対応します。競合があると一括処理は実行されません。直前に成功した一括処理は取り消せ、中断した処理は復旧できます。
- コマンドパレットで UUID の生成、タイムスタンプから日付への変換、JSON の整形と圧縮、Base64 と URL のエンコードとデコード、重複行の削除ができます。操作はよく使う項目に固定でき、最近実行した操作は上部に残ります。
- グローバルショートカットで、MooTool がバックグラウンドのときもコマンドパレットを開けます。既定は macOS の ⌘⇧Space、Windows と Linux の Ctrl+Shift+Space です。固定した操作はトレイからも開けます。
- JSON ワークスペースのステータスバーに、現在のファイルパスと未保存マークを表示します。
- ダークモードのツール作業領域は Islands Dark の配色です。アプリのサイドバーは従来の質感のままです。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
