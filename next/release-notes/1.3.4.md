# MooTool Next Electron 1.3.4

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.4<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Installers are smaller. Libraries used only by the interface are compiled into the app and are no longer shipped again as full packages.
- On Windows and Linux, text recognition is no longer inside the installer. The first time you recognize text or capture a screenshot for OCR, MooTool shows the download size and waits for confirmation. The download continues if you close the dialog, and a failed download can be retried. After verification, restart to use it; other tools keep working before the restart. The component is stored in your user data, reused after updates, and later recognition stays offline. macOS still uses Apple Vision and does not download a model.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.3.4<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- 安装包更小。只用于界面的库会编译进应用，不再作为完整依赖包重复分发。
- Windows 和 Linux 的文字识别不再放进安装包。首次识别文字或截图识字时，会显示下载大小并等待确认。关闭窗口后下载仍会继续，失败可以重试。校验完成后重启即可使用；重启前其他工具仍可使用。组件保存在用户数据目录，应用升级后继续复用，之后的识别保持离线。macOS 仍使用 Apple Vision，不下载模型。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.3.4<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 修正と改善

- インストーラーが小さくなりました。画面だけで使うライブラリはアプリに組み込まれ、完全なパッケージとして重複配布されません。
- Windows と Linux では、文字認識をインストーラーに同梱しなくなりました。初めて文字認識または画面キャプチャ認識を使うとき、ダウンロードサイズを表示して確認を待ちます。画面を閉じてもダウンロードは続き、失敗したときは再試行できます。検証後に再起動すると使えるようになり、再起動前も他のツールは使えます。コンポーネントはユーザーデータに保存され、アップデート後も再利用できます。その後の認識はオフラインです。macOS は引き続き Apple Vision を使い、モデルをダウンロードしません。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
