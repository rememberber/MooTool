# MooTool Next Electron 1.3.2

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.2<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Image Assistant can resize a batch of images. Choose a preset or pixel size, then proportional fit, centered crop, or stretch, and preview each output size before processing. Shrink-only and keeping the originals are on by default. Outputs are PNG or JPEG, with per-image progress and cancel.
- The command palette can turn rich text into Markdown, convert a table to JSON, and show clipboard plain text or HTML source. Results are previewed first. Any text result can be saved as a file.
- Image Assistant can recognize text in the current image or a selected screenshot region. macOS 13 and later uses local Apple Vision. Windows and Linux use an offline PP-OCRv6 model for Simplified Chinese, Traditional Chinese, English, and Japanese. The original image stays unchanged, and the clipboard is updated only when you copy or save.
- Quick File Preview opens up to 100 text, image, or PDF files. Switch with the list or the arrow keys. Text and JSON use the read-only editor, and images and PDF pages zoom locally. Find text in the current preview; returning to a file in the same batch restores its reading position.
- Opening the command palette from a tool view returns keyboard focus to the search field.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

### 修复与改进

- 图片助手可以批量调整尺寸。可选用预设或填写像素，再选择等比适应、居中裁剪或拉伸，并在处理前预览每张图的实际输出尺寸。默认只缩小并保留原图。输出为 PNG 或 JPEG，逐张显示进度，也可取消。
- 命令面板可以把富文本转为 Markdown、把表格转为 JSON，并查看剪贴板纯文本或 HTML 源码。结果先预览。任意文本结果都可以保存为文件。
- 图片助手可以识别当前图片或框选截图中的文字。macOS 13 及以上使用本机 Apple Vision。Windows 和 Linux 使用离线 PP-OCRv6 模型，支持简体中文、繁体中文、英文和日文。原图不会被改写，只有复制或保存时才更新剪贴板。
- 文件快速预览一次可打开最多 100 个文本、图片或 PDF。可用列表或左右方向键切换。文本和 JSON 使用只读编辑器，图片和 PDF 页面在本地缩放。可在当前预览中查找文本；同一批文件切回时会恢复阅读位置。
- 从工具视图打开命令面板时，键盘焦点会回到搜索框。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

### 修正と改善

- 画像アシスタントで画像を一括リサイズできます。プリセットまたはピクセル寸法を選び、等比フィット、中央クロップ、伸縮のいずれかを指定して、処理前に各画像の出力サイズを確認します。縮小のみと元画像の保持が既定です。出力は PNG または JPEG で、画像ごとに進捗を表示し、中断もできます。
- コマンドパレットでリッチテキストを Markdown に、表を JSON に変換し、クリップボードのプレーンテキストまたは HTML ソースを表示できます。結果は先にプレビューします。テキスト結果はファイルとして保存できます。
- 画像アシスタントで、現在の画像または選択したスクリーンショット領域の文字を認識できます。macOS 13 以降はローカルの Apple Vision を使います。Windows と Linux はオフラインの PP-OCRv6 モデルを使い、簡体字中国語、繁体字中国語、英語、日本語に対応します。元画像は変更せず、コピーまたは保存したときだけクリップボードを更新します。
- クイックファイルプレビューは、テキスト、画像、PDF を一度に最大 100 件開けます。一覧または左右キーで切り替えます。テキストと JSON は読み取り専用エディターを使い、画像と PDF ページはローカルで拡大縮小します。現在のプレビュー内を検索でき、同じバッチのファイルに戻ると閲覧位置を復元します。
- ツールビューからコマンドパレットを開くと、キーボードフォーカスが検索欄に戻ります。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
