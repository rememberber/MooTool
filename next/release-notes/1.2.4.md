# MooTool Next Electron 1.2.4

## English

> Product: MooTool Next Electron<br>
> Version: 1.2.4<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- AES now uses the raw UTF-8 key and accepts exactly 16, 24, or 32 bytes, matching Java. Ciphertext from the old Electron key handling can still be decrypted with an explicit option.
- Regex defaults to the Java engine and requires JDK 11 or newer. JavaScript mode remains available. Matches update as you type, are highlighted in the source, and can be stepped through. Favorites support groups, editing, reordering, and batch delete.
- JSON documents and Quick Notes support multi-select copy and export.
- Color favorites can be edited, reordered, and deleted in batches, and show a larger color swatch.
- Calculator and Regex restore the last draft after restart, including drafts migrated from MooTool Java.
- Image compression, watermarking, and SVG conversion show per-file progress, continue after a failure, and can be cancelled.
- HTTP can send a request into its own response window. An open window keeps that response snapshot.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.2.4<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- AES 使用原始 UTF-8 密钥，只接受 16、24 或 32 字节，与 Java 对齐。旧 Electron 密钥处理生成的密文，可勾选选项后解密。
- 正则默认使用 Java 引擎，需要 JDK 11 或更新版本；仍可切换到 JavaScript。输入后自动匹配，在原文中高亮，并可前后定位。收藏支持分组、编辑、排序和批量删除。
- JSON 文档和随手记支持多选复制、多选导出。
- 调色板收藏可以编辑、排序和批量删除，并用更大的色块展示颜色。
- 计算器和正则会在重启后恢复上次草稿，也包括从 MooTool Java 迁移来的草稿。
- 图片压缩、水印和 SVG 转换会显示逐项进度，单项失败后继续处理，并可以取消。
- HTTP 可以把请求发送到独立响应窗口。已打开的窗口保留当时的响应快照。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.2.4<br>

### 修正と改善

- AES は生の UTF-8 キーを使い、16、24、32 バイトのみを受け付け、Java と揃えます。旧 Electron のキー処理で作った暗号文は、明示的なオプションで復号できます。
- 正規表現は既定で Java エンジンを使い、JDK 11 以降が必要です。JavaScript モードも残しています。入力に合わせて一致を更新し、原文で強調表示し、前後へ移動できます。お気に入りはグループ、編集、並べ替え、一括削除に対応します。
- JSON ドキュメントとクイックノートで、複数選択のコピーとエクスポートができます。
- カラーお気に入りは編集、並べ替え、一括削除ができ、より大きい色見本を表示します。
- 電卓と正規表現は再起動後に前回の下書きを復元します。MooTool Java から移行した下書きも含みます。
- 画像の圧縮、透かし、SVG 変換はファイルごとの進捗を表示し、1 件失敗しても続行でき、キャンセルできます。
- HTTP はリクエストを独立した応答ウィンドウへ送信できます。開いたウィンドウはその応答のスナップショットを保持します。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
