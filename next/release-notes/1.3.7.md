# MooTool Next Electron 1.3.7

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.7<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Markdown Quick Notes can show an outline of headings. Choosing a heading jumps to it in the editor, preview, and split view. Headings inside code blocks are skipped, and the outline is available only while the note uses Markdown.
- A Markdown file that has no note metadata opens as Markdown.
- Export keeps each file's suffix, including extra dots and capitalization. A legacy `.txt` note whose language is not plain text is exported with that language's suffix, such as `.md`, `.sql`, or `.json`.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.3.7<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- Markdown 随手记可以显示标题大纲。选择标题后，会在编辑、预览和分栏视图中跳到对应位置。代码块里的标题不会列入大纲，并且只有笔记语法为 Markdown 时才提供大纲。
- 没有笔记元数据的 Markdown 文件会按 Markdown 打开。
- 导出时保留每个文件自己的后缀，包括名称中的额外圆点和原来的大小写。仍使用 `.txt` 文件名、但语言不是纯文本的旧笔记，会按语言导出为对应后缀，例如 `.md`、`.sql` 或 `.json`。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.3.7<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 修正と改善

- Markdown のクイックノートで見出しのアウトラインを表示できます。見出しを選ぶと、編集、プレビュー、分割表示の該当位置へ移動します。コードブロック内の見出しは含まれず、ノートの構文が Markdown のときだけ使えます。
- ノートのメタデータがない Markdown ファイルは Markdown として開きます。
- 書き出しでは、名前の中の追加のドットや大文字小文字を含め、各ファイルの拡張子を保持します。ファイル名は `.txt` のままで言語がプレーンテキストではない古いノートは、`.md`、`.sql`、`.json` など、その言語の拡張子で書き出します。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
