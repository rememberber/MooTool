# MooTool Next Electron 1.1.3

## English

> Product: MooTool Next Electron<br>
> Version: 1.1.3<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Features

- More app-like main layout and dialogs; settings open as a dedicated page instead of a popup.
- Pin / unpin tool windows from the left navigation, with per-tool custom drag regions.
- Color palette supports multiple favorite folders (aligned with Java) and a proper favorite button.
- Notes: create copy, export, and document info moved to the left-list context menu; Git sync also available from the menu.
- Recent tools in feature navigation are off by default.

### Fixes and improvements

- Immersive title-bar / drag-region polish across Notes, JSON, Text Diff, HTTP, Message Board, and other tools.
- JSON “More tools” and Notes quick-replace panels resize with the splitter.
- Fixed detached-window traffic lights disappearing under the cursor; improved light-mode navigation dividers.
- Notes / JSON layout tweaks (search on top, denser side panes).

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.1.3<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 新功能

- 主布局与对话框更偏桌面 App 风格；设置改为独立页面打开，不再弹窗。
- 左侧导航支持打开 / 收回独立窗口；各功能区按内容定制可拖拽区域。
- 调色板支持多个收藏夹（对齐 Java），并补齐收藏按钮。
- 随手记：创建副本、导出、文档信息移至左侧右键菜单；Git 同步同步加入菜单（工具栏保留）。
- 功能导航中「显示最近使用」默认关闭。

### 修复与改进

- 随手记、JSON、文本对比、HTTP、留言板等页面沉浸式顶栏与拖拽区域优化。
- JSON「更多工具」与随手记快捷替换栏可随分割线动态变宽。
- 修复独立窗口红绿灯悬停消失；优化亮色模式下左侧分割线表现。
- 随手记 / JSON 左侧布局调整（搜索置顶、栏间距收紧）。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.1.3<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 新機能

- メインレイアウトとダイアログをよりデスクトップアプリ向けに刷新。設定はポップアップではなく専用ページで開きます。
- 左ナビからツールウインドウのピン留め／解除に対応し、各ツールに合わせたドラッグ領域を用意しました。
- カラーパレットで複数のお気に入りフォルダーに対応（Java 版に準拠）し、お気に入りボタンを追加しました。
- クイックノート：コピー作成・エクスポート・ドキュメント情報を左リストの右クリックへ移動。Git 同期もメニューに追加（ツールバーは維持）。
- 機能ナビの「最近使用」は既定でオフです。

### 修正と改善

- クイックノート、JSON、テキスト比較、HTTP、伝言板などの没入型タイトルバー／ドラッグ領域を改善。
- JSON「その他のツール」とクイックノートのクイック置換パネルがスプリッターに追従して幅変更されます。
- 独立ウインドウの信号機ボタンがカーソル下で消える問題を修正。ライトモードのナビ区切り線も改善。
- クイックノート／JSON の左レイアウトを調整（検索を最上段へ、余白を縮小）。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
