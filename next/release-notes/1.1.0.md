# MooTool Next Electron 1.1.0

## English

> Product: MooTool Next Electron<br>
> Version: 1.1.0<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Features

- System environment variables tool now supports viewing and directly editing variables.
- Network tool adds IP-range reachability checks (for example `192.168.10`) and lists hosts that respond to ping for network debugging.
- Quick Notes adds adjustable line spacing.

### Improvements

- Upgraded dependencies to the latest compatible versions.
- Optimized Git lock handling for Notes / JSON vault operations.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.1.0<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 新功能

- 系统环境变量工具支持查看并直接修改环境变量。
- 网络工具新增 IP 段可达性检测（例如输入 `192.168.10`），输出可 ping 通的具体 IP，便于网络排查。
- 随手记新增行距调节功能。

### 改进

- 升级依赖至最新兼容版本。
- 优化随手记 / JSON 的 Git 锁处理。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

### 新機能

- システム環境変数ツールで変数の表示と直接編集に対応しました。
- ネットワークツールに IP 範囲の到達性チェックを追加（例：`192.168.10`）。ping 可能な IP を一覧表示し、ネットワーク調査に役立ちます。

### 改善

- 依存関係を最新の互換バージョンへ更新しました。
- クイックノート／JSON の Git ロック処理を最適化しました。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
