# MooTool Next Electron 1.2.3

## English

> Product: MooTool Next Electron<br>
> Version: 1.2.3<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Cron now matches the Java edition more closely: a visual field editor, common expressions, grouped favorites with ordering, natural-language descriptions, and the next run times.
- Translation adds DeepL with an API key saved in Settings, identifier splitting, and copying short English names as camelCase, PascalCase, snake_case, UPPER_SNAKE_CASE, or kebab-case.
- Image Assistant accepts the system paste shortcut while the tool is active.
- Java, Node, Python, and similar runtimes are discovered from the login shell PATH, including Homebrew and version managers.
- Expired cached macOS update installers are removed. A download in progress is kept.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.2.3<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- Cron 更接近 Java 版：可视化字段编辑、常用表达式、分组收藏与排序、自然语言描述，以及最近运行时间。
- 翻译新增 DeepL（在设置中保存 API Key）、拆分标识符，以及把较短的英文结果复制为 camelCase、PascalCase、snake_case、UPPER_SNAKE_CASE 或 kebab-case。
- 图片助手在当前工具激活时支持系统粘贴快捷键。
- Java、Node、Python 等运行时会从登录 shell 的 PATH 中查找，包括 Homebrew 和版本管理器。
- 过期的 macOS 更新安装包缓存会被清理，正在下载的文件会保留。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.2.3<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 修正と改善

- Cron が Java 版により近くなりました。視覚的なフィールド編集、よく使う式、グループ付きお気に入りと並べ替え、自然言語の説明、次回実行時刻に対応します。
- 翻訳に DeepL（設定で API キーを保存）、識別子の分割、短い英語名を camelCase、PascalCase、snake_case、UPPER_SNAKE_CASE、kebab-case でコピーする機能を追加しました。
- 画像アシスタントは、ツールがアクティブなときにシステムの貼り付けショートカットを受け付けます。
- Java、Node、Python などのランタイムをログインシェルの PATH から見つけます。Homebrew やバージョンマネージャーも対象です。
- 期限切れの macOS 更新インストーラーキャッシュを削除します。ダウンロード中のファイルは残します。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
