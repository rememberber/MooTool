# MooTool Next Electron 1.3.5

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.5<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- The first launch follows the system language when it is Chinese, English, or Japanese. A language you already saved is kept.
- Calculator base conversion handles hexadecimal and binary fractions exactly, including optional `0x` and `0b` prefixes. Fractions that would repeat are reported instead of rounded. A separate section decodes IEEE 754 32-bit and 64-bit hexadecimal values, with big-endian or little-endian byte order.
- Dialogs keep keyboard focus inside, and Esc closes the top dialog. Clicking the backdrop keeps what you entered. Destructive confirmations focus Cancel. Errors stay until you dismiss them and can be copied. Settings can turn off hiding the window with Esc.
- An empty JSON workspace can create a snippet, import a file, or start from a sample. Import keeps the original text, including large integers and duplicate keys.
- PDF results can open the file, reveal it in its folder, or copy the path. Cancelling a merge or split does not overwrite the target file.
- Large JSON work and text comparison run in the background, and PDF processing runs off the interface thread. The first unexpected tool crash reloads that view; a second crash within 30 seconds asks you to reload.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

### 修复与改进

- 首次启动会按系统语言选择中文、英文或日文。已经保存的语言设置会保留。
- 计算器的进制转换可以精确处理十六进制和二进制小数，也支持可选的 `0x` 和 `0b` 前缀。无法在目标进制中写尽的小数会报错，而不是四舍五入。另有 IEEE 754 单精度和双精度十六进制解码，可选大端或小端字节序。
- 弹窗会把键盘焦点留在内部，Esc 关闭最上层弹窗。点击遮罩会保留已输入的内容。危险确认默认聚焦“取消”。错误提示会一直显示到手动关闭，并可以复制。设置里可以关闭“按 Esc 隐藏窗口”。
- JSON 工作区没有选中文件时，可以新建片段、导入文件或用示例新建。导入保留原始文本，包括大整数和重复键。
- PDF 结果可以打开文件、在文件夹中显示或复制路径。取消合并或拆分不会改写目标文件。
- 较大的 JSON 处理和文本对比改在后台执行，PDF 处理也不再占用界面线程。工具意外崩溃后会先自动重载；30 秒内再次崩溃时改为提示手动重载。

- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

### 修正と改善

- 初回起動時は、システム言語が中国語、英語、日本語のいずれかならそれに合わせます。保存済みの言語設定はそのまま残ります。
- 電卓の基数変換で、16 進数と 2 進数の小数を正確に扱えます。任意の `0x` と `0b` 接頭辞にも対応します。変換先で循環する小数は丸めず、エラーになります。別に IEEE 754 の単精度と倍精度の 16 進値を復号でき、ビッグエンディアンとリトルエンディアンを選べます。
- ダイアログはキーボードフォーカスを内側に保ち、Esc で最前面のダイアログを閉じます。背景をクリックしても入力内容は残ります。危険な確認は「キャンセル」にフォーカスします。エラーは手動で閉じるまで表示され、コピーできます。設定で Esc によるウィンドウ非表示をオフにできます。
- JSON ワークスペースでファイルが選ばれていないとき、断片の新規作成、ファイルの取り込み、サンプルからの作成ができます。取り込みは大きな整数や重複キーを含む元のテキストを保持します。
- PDF の結果から、ファイルを開く、フォルダーで表示する、パスをコピーできます。結合や分割をキャンセルしても、対象ファイルは上書きされません。
- 大きな JSON 処理とテキスト比較はバックグラウンドで実行し、PDF 処理もインターフェースのスレッドを占有しません。ツールが予期せずクラッシュしたときはまず自動で再読み込みし、30 秒以内に再度クラッシュした場合は手動での再読み込みを案内します。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
