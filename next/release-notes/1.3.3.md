# MooTool Next Electron 1.3.3

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.3<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Command palette results use syntax highlighting. JSON actions highlight JSON, rich text to Markdown highlights Markdown, and clipboard HTML highlights HTML. The preview stays read-only.
- JSON results can be imported into the JSON workspace as a new file. Other results can be imported into Quick Notes as a new note, using Markdown, HTML, or plain text. Import does not overwrite existing files or change the clipboard. If import fails, the preview stays open so the result can be copied or tried again.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.3.3<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- 命令面板的结果预览支持语法高亮。JSON 相关动作高亮 JSON，富文本转 Markdown 高亮 Markdown，剪贴板 HTML 高亮 HTML。预览保持只读。
- JSON 结果可以导入 JSON 工作台并生成新文件。其他结果可以导入随手记并生成新笔记，按内容使用 Markdown、HTML 或纯文本。导入不会覆盖已有文件，也不会改写剪贴板。导入失败时预览仍保留，可以复制或重试。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.3.3<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 修正と改善

- コマンドパレットの結果プレビューで構文を強調表示します。JSON の操作は JSON、リッチテキストから Markdown への変換は Markdown、クリップボード HTML は HTML を強調します。プレビューは読み取り専用です。
- JSON の結果は JSON ワークスペースへ取り込み、新しいファイルを作成します。その他の結果はクイックノートへ取り込み、内容に応じて Markdown、HTML、またはプレーンテキストの新しいノートを作成します。取り込みは既存ファイルを上書きせず、クリップボードも変更しません。失敗したときはプレビューが残るので、コピーするか再試行できます。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
