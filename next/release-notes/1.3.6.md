# MooTool Next Electron 1.3.6

## English

> Product: MooTool Next Electron<br>
> Version: 1.3.6<br>
> This release is installed and updated independently from MooTool Java and does not overwrite the Java edition.

### Fixes and improvements

- Installed builds can be chosen in Open With for JSON, JSONC, TXT, LOG, Markdown, XML, YAML, HTML, JavaScript, TypeScript, Java, Python, and SQL files. MooTool does not change the system default by itself. On macOS, move the app into Applications and set it in Finder → Get Info → Open With. On Windows, the NSIS installer registers the types; the portable build does not. On Linux, the deb build can be selected in the file manager; an AppImage needs desktop integration first.
- Opening a supported file brings MooTool forward and asks whether to add a copy to Quick Notes or the JSON workspace. Duplicate names are numbered, and the source file is never modified. Quick Notes keep the source syntax. The JSON workspace keeps the original text, including incomplete JSON. Several files are handled in order, including files opened while MooTool is starting or already running.
- Text imports accept UTF-8 and BOM-marked UTF-16 up to 20 MB. Binary, unsupported, missing, or unreadable files show an error and do not block the remaining files.

### Notes

- Installers remain unsigned. On macOS, the app downloads and verifies the new DMG, then asks the user to open it and drag the app into Applications.
- The Java product line continues to use `v*` tags and its existing update manifest.

## 中文

> 产品线：MooTool Next Electron<br>
> 版本：1.3.6<br>
> 本版本与 MooTool Java 独立安装、独立更新，不会覆盖 Java 版本。

### 修复与改进

- 安装版可以作为“打开方式”的候选，支持 JSON、JSONC、TXT、LOG、Markdown、XML、YAML、HTML、JavaScript、TypeScript、Java、Python 和 SQL。应用不会自行改掉系统默认程序。macOS 需要先把应用放进“应用程序”，再在访达的“显示简介 → 打开方式”里选择。Windows 由 NSIS 安装包登记这些类型，便携版不会登记。Linux 可在文件管理器里选择 deb 安装的版本；AppImage 需要先完成桌面集成。
- 打开受支持的文件时，MooTool 会回到前台，并询问添加到随手记还是 JSON 工作台。导入的是独立副本，同名文件会自动编号，原文件不会被修改。随手记保留源文件的语法。JSON 工作台保留原始文本，包括还不完整的 JSON。多个文件会按顺序处理，启动过程中或应用已在运行时收到的请求也会处理。
- 文本导入支持 UTF-8 和带 BOM 的 UTF-16，单个文件最大 20 MB。二进制、不支持、缺失或无法读取的文件会提示错误，不影响后面的文件。

### 说明

- 安装包仍未签名。macOS 会下载并校验新版 DMG，随后提示用户打开 DMG 并将应用拖入“应用程序”。
- Java 产品线继续使用 `v*` tag 和原有更新清单，不受本次发布影响。

## 日本語

> 製品ライン：MooTool Next Electron<br>
> バージョン：1.3.6<br>
> このリリースは MooTool Java とは独立してインストール・更新され、Java 版を上書きしません。

### 修正と改善

- インストール版は、JSON、JSONC、TXT、LOG、Markdown、XML、YAML、HTML、JavaScript、TypeScript、Java、Python、SQL の「このアプリケーションで開く」候補になります。システムの既定アプリは自動では変更しません。macOS ではアプリを「アプリケーション」に入れてから、Finder の「情報を見る → このアプリケーションで開く」で選びます。Windows では NSIS インストーラーが種類を登録し、ポータブル版は登録しません。Linux では deb 版をファイルマネージャーから選べます。AppImage は先にデスクトップ統合が必要です。
- 対応ファイルを開くと MooTool が前面に出て、クイックノートか JSON ワークスペースにコピーを追加するか確認します。同名ファイルには連番が付き、元のファイルは変更しません。クイックノートは元の構文を保持します。JSON ワークスペースは、不完全な JSON を含む元のテキストを保持します。複数ファイルは順番に処理し、起動中や実行中に届いた要求も処理します。
- テキストの取り込みは UTF-8 と BOM 付き UTF-16 に対応し、1 ファイル最大 20 MB です。バイナリ、未対応、見つからない、読み取れないファイルはエラーを表示し、残りのファイルは続行します。

### 補足

- インストーラーは引き続き未署名です。macOS では新しい DMG をダウンロードして検証し、その後 DMG を開いてアプリを「アプリケーション」へドラッグするよう案内します。
- Java 製品ラインは引き続き `v*` タグと従来の更新マニフェストを使用し、このリリースの影響を受けません。
