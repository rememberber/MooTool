# MooTool Next Flutter 0.1.0

> 产品线：MooTool Next Flutter
> 版本：0.1.0
> 本版本与 MooTool Java / Electron / Tauri / macOS Native 独立安装、独立更新，不会覆盖其他产品。
> 安装包未签名。下载后请校验并手动安装；应用不会提示自动安装成功。

## English

- First Flutter desktop line: 26 entries, JSON workspace, local tools, quick note, HTTP, media helpers, desktop host, and a next-flutter-only update check.
- Packages are unsigned. The client downloads and verifies SHA-512, then asks you to open the installer.
- Known gaps: no second Flutter engine, no ScreenCaptureKit overlay, no SM4/RSA/SM2, no QR decode, no Bing translator, no update-manifest node until assets exist.
