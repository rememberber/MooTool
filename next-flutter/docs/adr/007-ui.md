# ADR 007：UI 差异

- 状态：采纳
- 日期：2026-09-08

- 沉浸式工具区，无大标题/面包屑/整页卡片。
- Token 使用主指南 modern 色板。六种界面风格可写入 settings.json，但 quiet/hero/smartisan/miui-v5/claude 尚未有独立视觉，选择它们不会假装换皮。
- 强调色 6 个预设 id（yellow/coral/blue/green/red/purple）会进入 `ColorScheme`；旧值 `#4f83cc` 仍能解析。
- 导航默认 classic；grouped 显示组标题；card 尚未单独视觉。
- 快捷键：⌘/Ctrl+K 搜索，⌘/Ctrl+, 设置，⌘/Ctrl+F 查找，⌘/Ctrl+S 保存，⌘/Ctrl+Enter 格式化。macOS 显示 Command，通过 LogicalKeyboardKey 同时监听 Control。
- 分离窗口在 P2 为同 engine 状态机，不是原生独立 NSWindow。
