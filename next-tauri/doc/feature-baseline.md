# MooTool Next Tauri 1.0 功能基线

> - 基线版本：1

> - 产品范围：25 个正式工具 + 工作台能力

## 工程实验入口

`editor-lab` 和 `webview-lab` 是兼容性与回归入口，不计入 25 个正式工具。开发构建显示这两个入口，正式构建从产品导航隐藏，但保留底层回归代码。

`src/app/toolCatalog.test.ts` 固定验证以下不变量：

- 正式工具数量为 25，ID 无重复。
- 工程实验入口只有 `editor-lab`、`webview-lab`。
- 已交付正式工具状态必须显式维护。
