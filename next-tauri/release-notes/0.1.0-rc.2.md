# MooTool Next Tauri 0.1.0-rc.2

## English

MooTool Next Tauri is an independent desktop product with its own installation, data and update channel. This release does not replace MooTool Java or MooTool Next Electron.

- Fix updater progress event fields so the frontend receives downloaded bytes and total size correctly instead of displaying invalid progress.
- Serialize update publication dates as RFC 3339 so the release date can be displayed correctly.
- Update `time` to 0.3.47 and `serde_with` to 3.21.0 to address their known security advisories.
- Backport the upstream GLib string-variant iterator safety fix to the GTK3-compatible 0.18.5 dependency, with Linux debug and optimized regression tests.
- Retain all 25 tools, native WebView lifecycle features and the independent signed updater identity. The RC1 tag and published assets remain unchanged.

This is a pre-release. The fixes passed macOS x64/arm64, Windows x64 and Linux x64 CI, including 25-tool acceptance and 100 detach/dock stress cycles per platform. CI is not a substitute for real-device DPI, multi-display, IME, permission, credential-store or interactive installation/upgrade acceptance. Those checks remain separately tracked; a public RC1-to-RC2 upgrade is not claimed as completed by these release notes.

Updater artifacts are signed with the existing product-specific key. macOS packages use ad-hoc signing without Apple notarization, and Windows packages do not have Authenticode signing; operating-system trust warnings are expected. This candidate does not claim trusted stable-distribution readiness.

## 中文

MooTool Next Tauri 是独立安装、独立存储、独立更新的桌面产品线，不替代 MooTool Java 或 MooTool Next Electron。

- 修复更新进度事件的字段命名，使前端正确接收已下载字节数和总大小，避免进度显示异常。
- 将更新发布日期统一输出为 RFC 3339，修复发布日期无法正常显示的问题。
- 将 `time` 升级至 0.3.47、`serde_with` 升级至 3.21.0，修复对应的已知安全公告问题。
- 为 GTK3 依赖的 GLib 0.18.5 回移上游字符串 Variant 迭代器安全补丁，并增加 Linux 调试版和优化版回归测试。
- 保留全部 25 个工具、原生 WebView 生命周期能力及现有独立签名更新身份。RC1 标签和已公开的安装包保持不变。

本版本为候选预发布版。上述修复已通过 macOS x64/arm64、Windows x64、Linux x64 四平台 CI，每个平台均通过 25 工具验收及 100 轮分离/停靠压力测试。CI 不代表真实设备的 DPI、多屏、输入法、权限、凭据库及交互式安装/升级验收已完成；这些项目单独跟踪。本发布说明不将公开 RC1 到 RC2 的升级标为已验收。

更新包使用现有产品专属密钥签名。macOS 安装包为 ad-hoc 签名、未经 Apple 公证；Windows 安装包未使用 Authenticode 签名，操作系统可能显示信任警告。本候选版不代表已具备受信任正式发行条件。
