# MooTool Next Tauri 0.1.0

MooTool Next Tauri is an independent desktop product line. It installs, stores data, evolves, and updates separately from MooTool Java and MooTool Next Electron; it does not replace either product.

MooTool Next Tauri 是独立桌面产品线。它与 MooTool Java、MooTool Next Electron 独立安装、独立存储、独立演进、独立更新，不替代其他实现。

MooTool Next Tauri は独立したデスクトップ製品ラインです。MooTool Java および MooTool Next Electron とは個別にインストール、保存、開発、更新され、いずれの製品も置き換えません。

## 本版内容

- 冻结并交付 25 个正式工具，包括 Host、HTTP、本机代码运行、翻译、图片和 PDF。
- 使用 Tauri-owned 原生子 WebView，支持停靠、分离和工具状态保持。
- Rust Core 提供设置、SQLite 本地数据、网络请求、进程控制、结构化日志、系统诊断、完整备份与恢复。
- 新增全局操作历史，按用户设置的条数上限自动裁剪。
- JSON 工作台新增独立 Vault、冲突保护、外部变更监控、可恢复删除和受限 Git 操作。
- 完整备份 v2 覆盖独立数据库、设置、图片库和 JSON Vault；恢复前自动创建回滚副本，Vault 导入不会覆盖原外部目录。
- 设置页提供 Tauri 专属更新检查、下载进度、取消、签名验证、安装与重启；不会读取 Electron 更新节点。
- 独立 CI 生成四平台安装包、更新签名、静态更新清单和发布后提升元数据，并对安装包执行首次启动冒烟。

## Highlights (English)

- Ships 25 production tools with Rust-owned settings, SQLite data, network/process services, diagnostics, backup, and JSON Vault.
- Provides native Tauri tool WebViews with dock/detach lifecycle and state retention.
- Adds an isolated signed updater and release pipeline for macOS x64/arm64, Windows x64, and Linux x64.

## 主な内容（日本語）

- 25 個の正式ツールと、Rust 管理の設定、SQLite、ネットワーク・プロセス機能、診断、バックアップ、JSON Vault を提供します。
- Tauri 独自のツール WebView で、ドッキング、分離、状態保持をサポートします。
- macOS x64/arm64、Windows x64、Linux x64 向けの独立した署名付き更新・リリース基盤を提供します。

## 发布说明

- 当前版本号为 `0.1.0`，用于独立产品线开发预览。
- 所有更新产物都必须通过 Tauri updater 签名。0.x 预览包可能仅使用 macOS ad-hoc 签名或缺少 Windows Authenticode，因此系统可能显示信任警告；正式受信任分发需配置平台证书与 macOS 公证。
- Tauri Release 使用 `next-tauri-v*` 标签且不竞争仓库全局 `Latest`。
