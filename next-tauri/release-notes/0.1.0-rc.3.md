# MooTool Next Tauri 0.1.0-rc.3

## English

MooTool Next Tauri is an independent desktop product with its own installation, data and update channel. This release does not replace MooTool Java or MooTool Next Electron.

- Add file preview and batch rename. The product now includes 27 tools. File preview opens text, JSON, images and PDF, keeps each file's reading state, and highlights common source extensions. Batch rename previews conflicts, renames hard links and can undo from the same journal as Electron.
- Align the shell with Electron: six interface styles, a 12–18 font size, full-bleed two- and three-column workspaces, a language menu, and folded editor gutters.
- Quick Notes use the same file tree and Git workspace, including attachments, multi-select, and conflict handling. JSON Vault follows the same Git checkpoint and file-tree rules.
- Each tool can keep history, drafts and favorites. The command palette and tray expose the same quick actions, including the color picker and screenshot.
- Network, Host, HTTP, translation, crypto, encoding, JSON, time, color and the other workspaces follow Electron's formats, column sizes and interaction rules. Settings from Electron can be imported without copying secrets.
- The RC2 tag and its published installers stay unchanged.

This is a pre-release. Real-device checks for DPI, multiple displays, input methods, permissions, the credential store, and an interactive upgrade from RC2 remain separate and are not claimed here.

Updater artifacts are signed with the existing product-specific key. macOS packages use ad-hoc signing without Apple notarization, and Windows packages do not have Authenticode signing; operating-system trust warnings are expected. This candidate does not claim trusted stable-distribution readiness.

## 中文

MooTool Next Tauri 是独立安装、独立存储、独立更新的桌面产品线，不替代 MooTool Java 或 MooTool Next Electron。

- 新增文件预览和批量重命名，正式工具增加到 27 个。文件预览可打开文本、JSON、图片和 PDF，切换文件时保留各自的阅读状态，并按常见源代码扩展名高亮。批量重命名会预览冲突、处理硬链接，并使用与 Electron 相同的日志撤销。
- 界面对齐 Electron：六种界面风格、12–18 字号、铺满窗口的两栏和三栏工作区、语言菜单，以及可折叠的编辑器行号槽。
- 随手记使用同一套文件树和 Git 工作区，包含附件、多选和冲突处理。JSON Vault 使用同一套 Git 检查点和文件树规则。
- 各工具可以保留历史、草稿和收藏。命令面板和托盘提供相同的快捷动作，包括取色和截图。
- 网络、Host、HTTP、翻译、加解密、编码、JSON、时间、颜色及其他工作区对齐 Electron 的格式、分栏尺寸和交互。可以从 Electron 导入设置，且不会复制凭据。
- RC2 标签和已公开的安装包保持不变。

本版本为候选预发布版。真实设备上的 DPI、多屏、输入法、权限、凭据库，以及从 RC2 交互升级的验收单独跟踪，本发布说明不将其标为已完成。

更新包使用现有产品专属密钥签名。macOS 安装包为 ad-hoc 签名、未经 Apple 公证；Windows 安装包未使用 Authenticode 签名，操作系统可能显示信任警告。本候选版不代表已具备受信任正式发行条件。

## 日本語

MooTool Next Tauri は、インストール、データ保存、更新チャネルが独立したデスクトップ製品です。MooTool Java または MooTool Next Electron を置き換えるものではありません。

- ファイルプレビューと一括リネームを追加し、正式ツールは 27 個になりました。プレビューはテキスト、JSON、画像、PDF を開き、ファイルごとの表示状態を保持し、一般的なソース拡張子を強調表示します。一括リネームは競合を確認し、ハードリンクを扱い、Electron と同じ記録で元に戻せます。
- 画面を Electron に合わせました。6 種類の表示スタイル、12–18 の文字サイズ、ウィンドウ幅いっぱいの 2 列・3 列ワークスペース、言語メニュー、折りたためるエディターの行番号です。
- クイックノートは同じファイルツリーと Git ワークスペースを使い、添付、複数選択、競合処理を含みます。JSON Vault も同じ Git チェックポイントとファイルツリーの規則に従います。
- 各ツールは履歴、下書き、お気に入りを保持できます。コマンドパレットとトレイには同じクイック操作があり、スポイトとスクリーンショットを含みます。
- ネットワーク、Host、HTTP、翻訳、暗号、エンコード、JSON、時刻、色、その他のワークスペースは、Electron の形式、列幅、操作に従います。Electron の設定は資格情報をコピーせずに読み込めます。
- RC2 のタグと公開済み配布物は変更しません。

本バージョンはプレリリースです。実機の DPI、複数画面、IME、権限、資格情報ストア、および RC2 からの対話的な更新確認は別に管理し、完了したとはしていません。

更新配布物は既存の製品専用鍵で署名します。macOS は ad-hoc 署名で Apple 公証なし、Windows は Authenticode 署名なしのため、OS の信頼性警告が表示される場合があります。信頼済みの正式配布版ではありません。
