# MooTool Next Tauri 0.1.0-rc.1

MooTool Next Tauri 的首个候选版本。它是与 MooTool Java、MooTool Next Electron 独立安装、独立存储和独立更新的桌面产品线。

## 候选版本内容

- 提供 25 个正式工具，覆盖 JSON、文本处理、HTTP、主机与网络、运行时、编码加密、图片、PDF 和系统信息等场景。
- 使用 Rust 管理的原生工具 WebView，支持停靠、分离、关闭、恢复和跨操作状态保持。
- 提供设置、SQLite 本地数据、Quick Note、全局操作历史、JSON Vault、备份恢复、网络请求、进程控制、诊断和结构化日志。
- 提供独立的 Tauri updater 信任身份、四平台构建矩阵和更新清单，不读取或覆盖 Electron 更新通道。
- 发布门禁构建 macOS x64/arm64 DMG、Windows x64 NSIS、Linux x64 AppImage/deb，并验证安装包、首次启动和卸载边界。
- 新增原生性能基线报告，记录冷启动、25 工具加载与停靠、内存扩展、10,000 条 Quick Note、10 MiB JSON、100 MiB SHA-256 和安装包大小。

## Release candidate notes

- This is the first release candidate for the independent MooTool Next Tauri product line.
- Updater artifacts are signed with the product-specific Tauri updater identity.
- macOS builds may use ad-hoc signing and Windows builds may omit Authenticode until distribution certificates are configured, so operating systems can display trust warnings.
- Real-device DPI, multi-display, IME, screen-capture permission, keyring, update, and uninstall results are tracked separately from headless CI.

## リリース候補について

- MooTool Next Tauri 独立製品ラインの最初のリリース候補です。
- 25 個の正式ツール、ネイティブ WebView ライフサイクル、ローカルデータ、バックアップ、JSON Vault、署名付き更新基盤を含みます。
- 実機での DPI、複数ディスプレイ、IME、画面権限、資格情報ストア、更新・アンインストール確認は CI の結果と分けて記録します。
