# DIFF-048：HTTP 二进制另存与其余工具 1080 溢出/下拉

- 编号：DIFF-048
- 影响：F09 HTTP 二进制下载；F05/F06/F07/F15/F16/F17/F18/F21/F24 工具栏密度；ui-spec 1080「更多」
- 日期：2026-09-15

## 原行为（Electron）

HTTP 二进制/无法解码响应不能当文本文件保存。二维码纠错、时间单位是 compact `<select>`。1080–1439 把低频工具栏收入「更多」，保留运行/发送等主动作。

## 本产品行为

- 二进制响应保留原始 `bodyBytes`（不写入集合 JSON）；Body 页「另存原始字节」写出这些字节，预览仍是十六进制摘要。
- 二维码纠错 L/M/Q/H、时间秒/毫秒改为下拉。
- 内容宽 < 1440 时：正则/Cron 收藏与历史、PDF 历史与帮助、代码运行检测/选项/格式化/清空、计算器复制与历史、配置清空与历史、Protobuf 复制与历史，以及这些页的分离，收入「更多」。代码运行保留运行/停止。

## 理由

规格要求二进制给下载视图，不能把 hex 预览当文件。其余工具仍把历史/收藏/检测铺在工具栏上，1080 会挤掉主动作。

## 证据

`HttpEngineTest.binaryResponseKeepsOriginalBytesForDownload`。`desktopTest` **233/233**，见 `docs/evidence/2026-09-15-http-binary-overflow/`。真实窗口截图未取。

## 受影响范围

- 集合快照仍只存文本预览，不存 10 MiB 原始字节。
- Host/网络/UA/翻译/环境/系统/留言板工具栏溢出尚未收完。
- HTTP 正文仍非 `EditorHost` 语法高亮。
