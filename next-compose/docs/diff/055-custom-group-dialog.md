# DIFF-055：自定义分组独立弹层管理器

- 编号：DIFF-055
- 影响：A01 布局/自定义分组；对照 Electron `CustomGroupManager`
- 日期：2026-09-15

## 原行为（Electron）

侧栏「管理功能分组」打开 Dialog：左列表/右编辑、新建、开关勾选工具、删除先确认，**取消不写设置**，保存才提交。空名或未选工具禁用保存。

## 本产品行为

- 侧栏标题旁 `+` 与设置 → 布局「管理功能分组」打开同一弹层。
- 草稿在内存编辑；保存写入 `layout.customGroups`；取消/Esc 丢弃草稿。
- 删除仍先确认；空组不出现在侧栏（原行为保留）。
- 设置页不再内嵌整页开关列表。

## 理由

DIFF-053 已有开关与校验，但内嵌设置页，取消无法撤回，与 Electron 弹层工作流不一致。

## 证据

`CustomGroupDraftTest`：空名/空工具非法，persist 去空白。`desktopTest` **238/238**。

## 受影响范围

- 仍非 Electron 六套 CSS 逐选择器皮肤。
- 产品主窗 Tab/IME 手工、托盘 TCC、三平台安装未测。
