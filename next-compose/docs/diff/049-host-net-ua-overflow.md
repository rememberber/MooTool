# DIFF-049：Host/网络/UA/翻译/环境/系统/留言板 1080 溢出与 compact 下拉

- 编号：DIFF-049
- 影响：F08/F10/F11/F12/F19/F20/F25；ui-spec 1080 工具栏密度
- 日期：2026-09-15

## 原行为（Electron）

1080–1439 把低频工具栏收入「更多」，保留保存/应用/刷新/发送等主动作。翻译提供商与留言板对齐是 compact `<select>`，不把 Google/Bing 或左/居中铺成一排按钮。

## 本产品行为

- Host：标题栏历史/分离、编辑行「当前 hosts」/查找在内容宽 < 1440 时收入「更多」；保留名称、保存、应用。
- 网络：标题栏历史/分离、输出区复制/清空收入「更多」；保留 ifconfig/netstat 与停止。
- UA：历史/分离收入「更多」。
- 翻译：Google/Bing 改为下拉；复制/存单词/清空收入「更多」；标题栏分离收入「更多」；保留语言、交换、自动、立即。
- 环境变量：导出/分离收入「更多」；保留新增、刷新。
- 系统信息：复制/分离收入「更多」；保留刷新与序列号开关。
- 留言板：对齐改为下拉；标题栏分离收入「更多」。

## 理由

与 DIFF-045～048 同一类密度缺口：这些页仍把低频动作铺在工具栏上，1080 宽会挤掉主动作。

## 证据

无新增引擎单测（只改控件与溢出）。`desktopTest` **233/233**，见 `docs/evidence/2026-09-15-host-net-ua-overflow/`。真实窗口截图未取。

## 受影响范围

- 算法与权限行为未改。
- HTTP 正文仍非 `EditorHost` 语法高亮。
- 仍非 Electron 六套 CSS 逐选择器移植。
